# Problem Statement: Academic Resource & Student Task Management System

## Overview
Students often struggle to organize course assignments, keep track of academic deadlines, and quickly locate core study resources scattered across multiple channels. 

## Scope
This application provides a unified CLI-based tool for students and faculty. It supports persistent storage for personal tasks, deadlines, and learning materials without requiring complex database deployments.

## Target Users
- **Students**: To manage their personal academic tasks and view study materials.
- **Faculty/Tutors**: To upload and reference links and course resources.

## Major Requirements Included
1. **User Management Module**: Handles user profiles and system registration.
2. **Task Management Module**: Tracks individual assignments, completion states, and deadlines.
3. **Resource Directory Module**: Serves as a central repository for study links and reference materials.
